# ❤️ قلبي — نظام متابعة صحة القلب

سجلّ شخصي لمتابعة صحة قلبك: المواعيد القادمة، التحاليل والقيم، مستودع التقارير، والإجازات المرضية — كل ذلك في مكان واحد، يعمل **بدون إنترنت**، وبياناتك محفوظة **على جهازك فقط**.

---

## 🚀 كيف أبدأ؟

1. افتح ملف **`index.html`** بأي متصفح (جوال أو كمبيوتر).
2. ستجد بياناتك الأساسية مُعبّأة مسبقاً من تقريرك الطبي.
3. أضف مواعيدك وتحاليلك وتقاريرك من خلال الأزرار.

> 💡 على الجوال: افتح الملف ثم اختر «إضافة إلى الشاشة الرئيسية» ليصبح كالتطبيق.

---

## 🧩 الأقسام

| القسم | الوظيفة |
|------|---------|
| 🏠 **الرئيسية** | موعدك القادم + ملخص سريع لآخر القياسات |
| 📅 **المواعيد** | مواعيدك مع الدكتور (قادمة وسابقة) مع عدّاد للأيام |
| 📊 **التحاليل** | تتبّع قيمك (ضغط، نبض، كوليسترول...) مع رسم بياني للتطور |
| 🗂️ **التقارير** | مستودع تقاريرك وتحاليلك المرفقة (PDF / صور) |
| 📝 **الإجازات** | توثيق الإجازات المرضية ومرفقاتها |
| 📋 **ملخص حالتي** | معلوماتك، تشخيصك، أدويتك، وملاحظات الطبيب |

---

## 📎 كيف أضيف ملف تقرير أو تحليل؟

1. ضع ملف الـ PDF أو الصورة داخل مجلد **`reports/`** بجانب التطبيق.
2. في قسم **التقارير**، اضغط «+ تقرير جديد» واكتب **اسم الملف** تماماً (مثل `ecg-2026.pdf`).
3. سيظهر رابط 📎 لفتح الملف مباشرة.

---

## 💾 النسخ الاحتياطي (مهم)

البيانات محفوظة في متصفحك فقط. لحمايتها:

- اضغط **«⬇️ نسخة احتياطية»** بشكل دوري لتنزيل ملف بياناتك (`qalbi-backup-YYYY-MM-DD.json`).
- لاستعادتها أو نقلها لجهاز آخر، اضغط **«⬆️ استيراد»** واختر الملف.
- احفظ النسخة الاحتياطية في مكان آمن (Google Drive مثلاً).

---

## 🔒 الخصوصية

- لا يُرسل أي شيء لأي خادم. كل بياناتك تبقى محلية على جهازك.
- لا يتطلب تسجيل دخول ولا إنترنت.

---

## 📂 محتويات المشروع

```
My-heart/
├── index.html      ← التطبيق (افتحه للبدء)
├── reports/        ← ضع ملفات تقاريرك وتحاليلك هنا
├── data/           ← نسخة احتياطية أولية من بياناتك (seed.json)
├── templates/      ← قوالب نصية جاهزة للتقارير والمواعيد
└── README.md
```
